# Fixed-S0 reset with 80% real / 20% synthetic targets

**Setup in progress; full training is unlaunched.** This arm imports S0, final-epoch-5 S1 and D2 from the new [20/80 continued job](../continued_mixed_20_final5/README.md). The campaign binds its source only after that job is complete and its private backup is sealed. The source placeholder in this condition's configuration is not a standalone launch target.

The first new stage is cycle 2. Both 20/80 arms use the identical M2 training tokens, real/synthetic selections, source labels and permutation; their initializers differ, S0 for reset versus S1 for continued. Stages 2–10 always initialize from S0 and use mixtures containing 30,357 real + 7,589 synthetic 64-token blocks. Later pools are generated by this reset arm's preceding selected model. Each stage executes five epochs, retains epoch 5 and restarts AdamW and the scheduler.

The smoke profile runs stages 2–3 with 205 real + 51 synthetic blocks and 64 validation/test blocks, sharing the newly created smoke S0/S1/D2/M2. Validation proves pipeline behavior, not scientific evidence of mitigation. A full branch cannot import a smoke source.

Use the [campaign](../../../comparisons/mixed_fraction_final5/README.md) for the tested launch/operations interface. Scientific definitions: [full.yaml](full.yaml), [smoke.yaml](smoke.yaml). [Shared methodology](../../../docs/methodology.md) and [metrics](../../../docs/metrics.md) apply unchanged.
