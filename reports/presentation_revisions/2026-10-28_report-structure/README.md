# Weekly report structure revision

Reorganised the main Google Docs research report on 28 October 2026. The separate
metric-explanation guide remains unchanged.

Methods, data accounting and metric definitions form complete explanatory blocks
before the relevant tables. Every native table now has a sequential numbered
caption describing its purpose. Findings, interpretation, checkpoint selection
and limitations have explicit subheadings rather than continuing an interrupted
list. The shared-start output examples occupy a coherent page with their caption.

All 11 table structures, styles and values, four figure objects, source links and
the original four-week plan are preserved. Existing prose was moved intact;
changes to its wording are confined to table numbers/cross-references and one
replaced grouping heading. No experiment data or historical reports were changed.

`editorial_plan.json` records the paragraph placements and added labels;
`google_doc_delivery.json` records native and rendered-PDF verification. Original
source snapshots and temporary PDF exports remain in ignored local state.
