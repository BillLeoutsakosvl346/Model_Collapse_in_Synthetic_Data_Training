# SmolLM2 seven-fraction analysis

The [authored report](../../report.md) contains 77 checkpoint rows, twenty square figure families (thirteen in Google Docs), six tables and two fixed same-prompt examples. Native tokenization is separate from the historical OPT bank. All seven conditions share one RTX PRO 4000 Blackwell and preserve continued AdamW/global cosine optimization.

## Reproduce the plots offline

Choose a new empty generated destination; this command uses only committed records and never reads credentials, provisions compute or runs inference:

```powershell
python -m scripts.analysis.build_smollm_fraction_report --records reports/20261111T210854Z-full-completion64-mixtures/records --out reports/20261111T210854Z-full-completion64-mixtures/generated/reproduce --opt-metrics reports/20261111T210854Z-full-completion64-mixtures/records/historical_opt_seven_fractions.json
```

The plots, trajectory metrics, examples and summary reproduce without private caches. This metadata-only replay does not repeat private probe/target diagnostics and writes an empty training-target diagnostic list. To recompute all 77 logical probes and all seven final mixed inputs, additionally provide `--bank PRIVATE_NATIVE_BANK --bulk PRIVATE_RECOVERY_ROOT`. The recorded analysis did perform those private-array checks. Bulk arrays and models must remain out of Git.

## Evidence and scope

- `metrics.csv`/`metrics.json`: fixed real continuation NLL/PPL, median/P95 losses, pooled/local diversity and repetition, formatting, optimizer steps, LR, time, memory and secondary full-text evaluations.
- `audit.json`: seventy recorded initializer/generator/optimizer handoffs, deterministic mixture selections, 1,610 stage-seal file references and direct arithmetic from saved real-test example losses. Hash/reference verification is not a cold restoration of all referenced model tensors.
- All 77 logical probe rows were recomputed from 71 unique arrays (one shared baseline plus seventy trained stages). Cycle-10 generated pools and actual input/mask arrays reconstruct exactly for all seven conditions, including the ten retained real targets in the 99.9% condition.
- `training_target_statistics.json` concerns 10,000 actual cycle-10 labels generated by M9 or retained from real source text. The plotted checkpoint probes concern 256 outputs generated by M10. Their pooled statistics have different population sizes.
- Entropy is empirical token-count entropy. Pooled entropy rises relative to real-only even while within-answer repetition worsens. It is not model predictive entropy or a standalone quality measure.
- `19_secondary_corpora` separates full-text evaluation from primary completion PPL. `20_cross_model_relative` uses each model's own baseline; tokenizer/windows/pretraining and some historical GPU placements differ, preventing a causal model-only comparison.
- One seed, ten cycles, five deterministic beams and cosine LR decay remain explicit limitations. The real-only control improves slightly; the data do not prove permanent stabilization, a universal real-data threshold or uniquely diagnose collapse rather than every form of overfitting/distribution shift.
- No full-run checkpoint cold restoration or GPU re-evaluation was performed by this report. Earlier two-update GPU acceptance restored one terminal stage and reproduced held-out evaluation; that is separate coverage. Full storage remains retained.

The analysis manifest records input hashes, script/revision, environment and output hashes. The publication manifest freezes original record bytes and final authored/generated files. Historical reports remain unchanged.
